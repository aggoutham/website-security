


A hands-on web security lab: the React frontend for the CSE543 (Web Security) assignment website.
Built from scratch and self-hosted by the course TA (nginx on a Raspberry Pi) for 80 graduate students learning advanced security concepts.
Students sign up, log in, and work through guided attack-and-defend tasks against a deliberately vulnerable app.
The task modules cover SQL injection, sensitive data exposure, cross-site scripting (XSS), and cross-site request forgery (CSRF).
Each task sets up a scenario, asks the student to exploit it and explain a mitigation, then verifies the result with a secret or password they recover.
The frontend talks to a separate hosted backend API (not part of this repo); screenshots of the site are below.
